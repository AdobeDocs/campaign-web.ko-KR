Adobe Campaign Web 사용자 인터페이스 릴리스는 기능 배포에 대한 보다 확장 가능한 단계별 접근 방식을 고려하는 연속 게재 모델에서 작동합니다. 따라서 이들 릴리스 정보는 월별로 여러 차례 업데이트됩니다. 이들 릴리스 정보를 정기적으로 확인하십시오.

>
>아래 기능 및 개선 사항에 대한 자세한 설명서는 향후 며칠에 걸쳐 점진적으로 추가될 예정입니다.

### 개선 사항 {#26-8-improvements}

* **열람수 추적**: 이제 Campaign Web 사용자 인터페이스에서 직접 열람수 추적을 활성화하거나 비활성화할 수 있습니다. 이는 데이터 보호 규정을 준수하는 데 도움이 됩니다.
* **프로그램 목록 보기**: 캠페인, 게재, 워크플로와 마찬가지로 이제 프로그램이 전용 보기에 나열됩니다. 이 보기에서 바로 기존 프로그램을 탐색하고 새 프로그램을 만들 수 있습니다.
* **사용자 정의 스키마 구성**: 이제 **액션 데이터** 섹션에서 사용자 정의 스키마의 레코드에 대한 **복제** 액션을 허용하지 않도록 설정할 수 있습니다.
  <!--* **Workflow and delivery templates (only msf???)**: When creating a new workflow or delivery, you must now explicitly select a template. A default template is no longer applied automatically.-->
* **사용자 정의 필터**: 스키마 편집기에서 사용자 정의 필터가 이제 직접 링크에 대한 필터링 조건을 지원하며, 새 **사용자 정의 필터 설정**&#x200B;을 사용하여 모든 속성의 기본 레이블을 재정의할 수 있습니다.
* **스키마 유효성 검사**: 이제 새 **유효성 검사** 버튼을 사용하여 스키마 편집기에서 바로 스키마 구조의 유효성을 검사할 수 있습니다.
* **폴더 보안**: 사용자가 **삽입** 또는 **편집** 액세스 권한을 가진 경우 이제 폴더에 대해 **이름 바꾸기** 옵션을 사용할 수 있습니다.
