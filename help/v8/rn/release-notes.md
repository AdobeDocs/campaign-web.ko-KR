### 개선 사항 {#26-7-improvements}

* **사용자 지정 스키마 구성**&#x200B;이 다음과 같이 개선되었습니다.
  * 새 **작업 데이터** 섹션을 사용하면 개별 폴더에 구성된 보안 규칙과 관계없이 사용자 지정 스키마 레코드에 사용할 수 있는 작업을 제한할 수 있습니다. [자세히 보기](../administration/schemas-action-data.md)
  * **사용자 지정 필터**&#x200B;이(가) **인벤토리 목록 구성** 섹션에 추가되었습니다. 목록 보기의 필터 창에서 빠른 액세스 필드로 표시할 속성을 선택할 수 있습니다. [자세히 보기](../administration/schemas-custom-filters.md)

* **워크플로**&#x200B;가 다음과 같이 개선되었습니다.
  * 이제 워크플로우 활동 삭제가 보다 유연해졌습니다. 활동에 후속 활동이 있으면 모든 활동을 삭제하도록 선택하거나, 선택한 활동만 삭제하도록 선택하거나, 후속 활동을 새 분기에 보관하면서 삭제할 수 있습니다. [자세히 보기](../workflows/orchestrate-activities.md#delete-activity)
  * 이제 두 워크플로우 활동 중 하나를 삭제하지 않고 두 워크플로우 활동 간의 전환 연결을 끊을 수 있습니다. 이를 통해 워크플로 다이어그램을 재구성하여 삭제할 활동 및 다시 만들 필요 없이 유지할 활동 그룹을 일시적으로 비울 수 있습니다. [자세히 보기](../workflows/orchestrate-activities.md#disconnect-transition)
  * 이제 가로 및 세로 스크롤 막대가 워크플로 캔버스 주위에 표시되므로 보려는 영역으로 직접 드래그하여 큰 워크플로를 탐색할 수 있습니다. [자세히 보기](../workflows/orchestrate-activities.md)
  * 이제 워크플로우를 저장하거나 시작/다시 시작할 때, 사용자가 연 이후에 다른 사용자가 웹 UI 또는 클라이언트 콘솔에서 워크플로우를 수정하면 경고가 표시됩니다. 다른 변경 내용을 재정의하거나, 워크플로우를 다시 로드하여 최신 버전을 가져오거나, 취소하도록 선택할 수 있습니다.

* **보낸 사람 전자 메일 주소**: 이제 **NmsDelivery_senderAddressMask** 옵션을 사용하여 게재의 **보낸 사람 전자 메일** 필드를 미리 정의된 주소 목록으로 제한할 수 있습니다. [자세히 보기](../administration/options.md#restrict-sender-address)
* **로그인 오류 메시지**&#x200B;이(가) 개선되었습니다. 로그인 시도에 실패하면 웹 UI에 여러 가지 상황에 대한 보다 구체적인 오류 메시지가 표시됩니다(예: 사용자에게 보안 영역이 할당되지 않았거나 IP 주소가 제한된 경우).
